# Multi-Thyroid Prediction

A frontend web application for a multi-class thyroid disease prediction system. The application provides a user-friendly interface for entering patient details, viewing prediction results, and managing prediction history.

## Features

- User login and registration
- Patient information management
- Thyroid disease prediction interface
- Prediction result display
- Prediction history
- Admin-related pages
- Responsive and user-friendly interface

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- JavaScript
- HTML
- CSS
